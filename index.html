¿Cómo funciona la estimulación multisensorial?

El cerebro del niño asocia tres vías simultáneas: Visual (resalta la sílaba y muestra el pictograma ARASAAC), Auditiva (inflexión de tono y duración con TTS) y Táctil (vibración corta para átonas, seca para acentuadas y prolongada para sostenidas).

Símbolos pictográficos propiedad del Gobierno de Aragón y creados por Sergio Palao para ARASAAC (CC BY-NC-SA).

➕ Añadir Nueva Palabra

Reglas de formato:
  • Separa sílabas con guión (-).
  • Sílabas en MAYÚSCULAS = Acentuadas (inflexión alta + vibración fuerte).
  • Sílabas con asterisco (*) = Sostenidas (se alargan + vibración prolongada).
Buscará automáticamente el pictograma oficial en la API de ARASAAC.

✏️ Editar Palabra

Reglas de formato:
  • Separa sílabas con guión (-).
  • MAYÚSCULAS = Acentuadas (ej. GUE).
  • Asterisco (*) = Sostenidas (ej. CHA*).
Si cambias el término, buscará el nuevo pictograma oficial.
